# 🗂 מאגר מסמכים ארגוני

אתר לניהול, חיפוש והורדת מסמכים. ממשק עברי מלא.

---

## 📋 דרישות מערכת

- **Node.js** גרסה 18 ומעלה — https://nodejs.org
- מערכת הפעלה: Windows / Mac / Linux

---

## 🚀 התקנה והרצה

### שלב 1 — פתח את תיקיית הפרויקט
```bash
cd docrepo
```

### שלב 2 — התקן חבילות
```bash
npm install
```

### שלב 3 — הפעל את השרת
```bash
npm start
```

### שלב 4 — פתח בדפדפן
```
http://localhost:3000
```

## 📁 מבנה הפרויקט

```
docrepo/
├── server.js          ← שרת Express + API
├── package.json       ← הגדרות Node.js
├── docrepo.db         ← בסיס נתונים SQLite (נוצר אוטומטית)
├── uploads/           ← קבצים שהועלו
└── public/
    └── index.html     ← ממשק המשתמש
```

---

## ⚙️ הגדרות מתקדמות

ניתן להגדיר משתני סביבה לפני ההרצה:

```bash
PORT=8080              # פורט (ברירת מחדל: 3000)
JWT_SECRET=סיסמה_סודית  # מפתח ל-JWT (חובה לשנות בייצור!)
```

### דוגמה — Windows:
```cmd
set JWT_SECRET=my_secret_key_here
npm start
```

### דוגמה — Mac/Linux:
```bash
JWT_SECRET=my_secret_key_here npm start
```

## 🔒 אבטחה

- סיסמאות מאוחסנות כ-hash (bcrypt)
- אימות JWT עם תפוגה של 8 שעות
- העלאת קבצים מוגבלת לסוגים מותרים בלבד (PDF, Word, Excel וכו')
- גודל קובץ מקסימלי: 50MB
